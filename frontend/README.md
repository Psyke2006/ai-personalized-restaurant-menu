# Frontend Development Guide

This folder contains the AI-coding instructions for the frontend workstream of the AI-Powered Personalized Restaurant Menu PBL.

## Read these files in order

1. `AI_FRONTEND_MASTER_PROMPT.md` — primary prompt to give Codex/Antigravity or another coding agent.
2. `API_INTEGRATION.md` — frontend-to-backend contract based on the repository's root `API.md`.
3. `UI_REQUIREMENTS.md` — pages, components, states, accessibility, and product behavior.
4. `IMPLEMENTATION_PLAN.md` — recommended incremental implementation and verification checklist.

## Before coding

From the repository root, inspect the actual `frontend/` files and read:

- `API.md`
- `ARCHITECTURE.md`
- `README.md`
- `CONTRIBUTING.md`
- `OWNERS.md`
- `frontend/package.json` (if present)

Treat the current repository as the source of truth for installed packages and existing code. Do not replace or recreate the frontend scaffold without a concrete reason.

## Placement

Copy these Markdown files into the repository's `frontend/` directory if you want the coding agent to find them beside the application. The canonical API and architecture documents remain at the repository root; do not make competing copies of them.
